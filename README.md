## Featured projects

### 🏛️ [Nepal Civic](https://github.com/Ashutosh-Neupane/nepal-civic): grievance platform for Nepal's federal structure

Citizens report local problems (roads, water, waste) in Nepali or English. Each grievance goes to the **ward office**; if the ward misses its deadline, it moves up automatically to the **Palika**, then the **District**, then the **Province**.

- All 7 provinces, 77 districts, 753 local levels and 6,743 wards
- Phone OTP sign-in over Sparrow SMS, map pins, photos and status tracking
- One set of officer screens for ward, Palika, district and province officers; the API limits each officer to their own area
- Bikram Sambat dates, Nepali digits, and a full English / नेपाली interface
- 238 backend tests

`React` · `TypeScript` · `Vite` · `Tailwind` · `Node.js` · `Express` · `PostgreSQL` · `Leaflet`

### 🏦 [Nepal Case Management](https://github.com/Ashutosh-Neupane/nepal-case-management): financial-crime investigation for Nepal

Banks file suspicious transaction reports and upload transactions. Detection rules flag cash over Rs 10 lakh, structuring, rapid movement, dormant accounts and large payments by politically exposed people. Analysts triage the alerts and investigate cases. A **second supervisor must approve** before a case goes to an agency such as the DMLI or CIAA.

- Role-based access for bank compliance officers, analysts, supervisors and admins
- Money-flow network for each subject, with links between known suspects
- Fiscal-year references (`CASE-2083/84-0001`), BS dates, and amounts in lakh and crore
- Unit tests for the rules and workflow, plus end-to-end API tests

`NestJS` · `Prisma` · `PostgreSQL` · `React` · `TanStack Query` · `Tailwind` · `Recharts`

### ☕ Crema: a modern desk for the Frappe framework

A Next.js replacement for Frappe Desk that runs against any Frappe v16 site without per-app code. It covers lists, forms, reports, workflows, workspaces, print views, calendar and Gantt views, file manager, inbox, and the real Frappe client-script runtime, so ERPNext's own form scripts keep working. Every feature is checked against Desk with end-to-end tests. *Repository going public soon.*

`Next.js 16` · `React 19` · `TypeScript` · `Tailwind 4` · `Frappe v16` · `ERPNext` · `Playwright`

## How I work

- **Start from the real workflow.** Who files it, who approves it, what happens when nobody acts. Then build the screens.
- **Enforce rules on the server.** Area limits, the four-eyes rule and roles live in the API, not just the UI.
- **Test against the real thing.** End-to-end tests against a live backend, not only mocks.
- **Small, honest commits** on feature branches, merged when they work.
